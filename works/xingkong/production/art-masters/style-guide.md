# 《星空情緣》關卡二 · 風格設定

狀態：**待 Helic 批准母版**。批准前不批量表情、不替換 `characters/*/0*.png` 正式線。  
對照：`game-ui/`（前 `ui-gameplay2`）、現有 `characters/` 候選立繪、`bg/` 空景。  
作者：梵高（2026-10-10）。對應 issue [#7](https://github.com/yoursun0/galgame/issues/7) 關卡二。

---

## 1. 畫風一句

半寫實學院風、溫柔筆觸，偏 Clannad 式半身立繪比例：人物大、對話框從簡。夜空／紙色／襯線 UI 皮膚跟 `game-ui`，**不抄**外來參考圖皮膚。人物可讀、不寫實照片、不二次元大眼過火。

## 2. 鎖定輸出尺寸

| 類型 | 像素 | 格式 | 備註 |
|------|------|------|------|
| 立繪母版／表情 | **1280×720** | PNG，RGBA 透明底 | 半身（腰上），人物置中；生成時綠幕 `#00FF00` 再 key |
| 全頁 CG | **1920×1080**（16:9） | JPEG | 全出血，無字、無框、無浮水印 |
| 背景空景 | **1920×1080**（16:9） | JPEG | 無人；可作對話框墊底 |
| 結局板（非試玩） | **1920×1080** | JPEG | 臉不畫清楚／遠景剪影（見既有 ending-*） |

試玩播放器若縮放，以 16:9 安全區為準；立繪左右留空給 ADV 對話條。

## 3. 立繪規則

- **母版**：正面或微側（≤15°），中性表情，鎖定臉、髮、衣、配飾。本目錄四張即候選母版。
- **表情包**：同一母版衍生；**須 Helic 批母版後**才批量。
- 半身裁到腰；手可入畫，腳與裙襬不強制。
- 角色之間髮色／衣色必須可辨：粉紅冷衫＝素婷；牛仔外套＝芷君；紅外套＋相機＝綺珊；灰風褸＋星吊墜＝凌晨。
- 不畫成人臉寫實、不模仿真人。

## 4. 背景／CG 規則

- 背景：空景、無人、無清楚五官路人；中文招牌能避則避（易亂碼）。
- CG：劇情關鍵一拍；可有人，但構圖服務情緒；試玩最小集見 [`cg-playtest.md`](cg-playtest.md)。
- 色溫：日間暖金／午後；草原夜冷藍＋銀河；SOC 午後刺眼光。
