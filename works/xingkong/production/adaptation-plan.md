## 1. 作品定位（企劃摘要）

- **題材／受眾**：校園觀星、友情與暗戀；繁體中文；適合已讀或願意跟原作節奏走的玩家。
- **視角**：第一人稱凌晨（玩家＝凌晨）。
- **原作忠實度**：主線事件、性格、關鍵對白以 `fiction.md` 為準；Galgame 只加「可辨識後果」的閘口選擇與結構性壓縮，不改人物為了進線而變性格。
- **完整作品目標**（README／PLAN）：素婷、芷君、綺珊三線；每線理想上 GOOD／TRUE／兩個 BAD。**v1 首版只做下方「品質試玩」一段**，不整本製作。
- **目標時長（整本，遠景）**：約 8–12 小時（待後續分章估）；首版試玩 **10–15 分鐘**。

## 2. 品質試玩範圍（10–15 分鐘）★必審

### 2.1 切點一句話

**從 SOC「話當年」開場，經車站派團刊、八達嶺、懸空寺，到草原觀星夜收束；驗三人立繪、三個有後果旗標、多場景 BGM／CG，不進中局三線分歧、不劇透結局。**

### 2.4 本段要驗的品質（對 PLAN §4.3）

1. 多人立繪與表情切換（凌晨、素婷、綺珊、芷君；家綸／會長可對話不強制立繪）。  
2. 實景背景切換：SOC → 車站／戶外 → 巴士 → 八達嶺 → 懸空寺 → 草原夜。  
3. 至少一張**全頁 CG**（建議優先：長城關口／可不可以先生／懸空寺「壯觀」／草原星空——見 [`asset-list.md`](asset-list.md)）。  
4. BGM 轉場（至少 3 首）。  
5. 選項有後果：三旗標在 `midcard` 旁白可**輕點**回顧（現有 `midcard.json` 已有類似口吻），**不**向玩家解釋 TRUE／GOOD。  
6. 段落收束卡（非結局）：停在草原星空／「背後有人叫我」之前即可。  
7. CG／場景回想：沿用播放器既有能力；試玩段內解鎖本段出現過的背景與 CG。

### 2.5 預估遊玩時長

twee Ch01–Ch04 正文約三千餘漢字＋4 個選擇點；含立繪／CG／點擊節奏，目標 **10–15 分鐘**（快讀約 8、細讀約 18——超出則再壓縮旁白，不砍三個旗標閘）。

## 4. 原作 vs 新增／壓縮／改結構

標記說明：**原作**＝`fiction.md` 有對應事件或對白；**壓縮**＝多段原文收成一場；**結構**＝敘事順序或載體調整、情節本身仍來自原作；**新增**＝原作無此玩家選擇或無此場，但人物口吻須仍像原作；**待確認**＝需 Helic 點頭才可進正式劇本。

| 段落 | 標記 | 說明 |
|------|------|------|
| SOC「話當年，就從這間房說起」加長、明確切入回憶 | **結構** | 取代原作每章開頭插敘一年後；內容仍指團刊遺在 SOC（原作第一話有） |
| 每章開頭一年後插敘（走出 SOC 撞人等） | **刪除（結構）** | 已定：倒敘只一次 |
| 車站／派團刊／裝酷對綺珊 | **原作** | 第一話 |
| 團刊「先說明遺留」選項 | **新增** | 閘出 `qishanHonest` |
| 八達嶺、手帕、素婷笑孱弱、芷君借零錢、「可不可以先生」 | **原作** | 第二話 |
| 長城「追上去」選項 | **新增** | 閘出 `sutingWalk` |
| 懸空寺大石、「壯觀」、綺珊惡作劇、狗 | **原作** | 第三話 |
| 當下問名 vs 胡扯緣訂七世 | **原作**有胡扯；問名＝**新增閘**（原作稍後由綺珊嚷出「黎芷君」） | |
| 草原激光筆、牛郎織女、去 set 望遠鏡 | **原作** | 第四話 |
| 「留下把話講完」 | **新增** | courage／`ch4_faced` |
| 多章 coffee corner 誠實 | **壓縮＋結構** | 收成離美前 coffee；candor 累加 |
| 三線剝離與 BAD／GOOD 閘 | **新增（結構）** | 結局情緒須能在原文找得到對應人物關係；**禁止發明新人物或改寫已定結局內容** |
| 玩家固定凌晨、無主角改名 | **原作** | |

角色外形、年齡未寫者標「正文沒寫」（見 `_bible.md`）；美術母版屬關卡二，本企劃不裁定臉／髮／衣。

## 5. 本段素材與粗成本

完整表見 [`asset-list.md`](asset-list.md)。

**品質試玩段最小集（數量級）**

- 背景：6（SOC、車站／戶外、巴士、八達嶺、懸空寺、草原夜）——倉庫已有對應檔可先佔位。  
- 立繪：4 人 × 試玩所需表情（約 3–5 張／人）；倉庫已有 5 表情／人（凌晨缺 03）。  
- 全頁 CG：試玩至少 **2** 張達正式品質（建議長城關口＋懸空寺或草原星空）；其餘可先用現有 cg 佔位。  
- BGM：≥3 首（倉庫已有多首 CC0 向）。  
- 音效：腳步／風／快門等 3–5 個（**多缺，待關卡二／音訊**）。

**粗成本（港幣／工時數量級，待 Helic 批預算上限）**

| 項目 | 估 |

| 關卡二樣板（梵高，另 PR） | 人設母版 4 人＋2 背景樣張＋1 CG 構圖：約 **8–16 工時**；若付費生圖另計預算 |
