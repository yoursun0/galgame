# README

我要把我寫的小說《星空情緣》改造成一隻GALGAME。玩法可以類似CLANNAD 或 G弦上的魔王 或 FATE/STAY NIGHT。由AI決定哪種更容易達成和效果更好。遊戲要在WEB上玩，也可以製作PWA讓人有手機遊玩。

《星空情緣》的故事原文在fiction.md

遊戲的主線劇情要盡量依照原文發展。角色的性格和對白也要參考原文。但GALGAME要有不同的支線劇情，玩到中局會按支線進入「素婷線」、「芷君線」和「綺珊線」。每條女角色線要有一個GOOD END, 一個TRUE END和兩個BAD END。

角色的造型可以參考images folder, 但你也可以為角色重新生成圖片和設計造型。每次有新造型就讓我REVIEW。
